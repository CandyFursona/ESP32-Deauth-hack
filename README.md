# ESP32-Deauth-hack
**Всё что в данном репозитории: лишь учебный материал, во многих странах это незаконно!**

# Линковщик
это работает только с оригинальным ESP32 (например ESP32-WROOM, ESP32 DevKit V1), в других (например ESP-C3, ESP-C5) способ может отличаться

В реальное время ESP32 на уровне ядра (по крайней мере на оффициальной библиотеке) запрещает Deauth кадры
что бы это исправить, надо сделать заглушку в коде, но, компилятор будет ругаться на то что в проекте 2 функции с одинаковым именем

1. перейдите в `C:\Users\YourName\AppData\Local\Arduino15\packages\esp32\hardware\esp32\` и в папку с цифрами (версия библиотеки)
2. в platform.txt найдите `compiler.c.elf.extra_flags=` и добавьте следующие флаги: `-Wl,-z,muldefs`
после этого в коде можно обойти проверку кадров при помощи такой заглушки (в коде этого репозитория она уже есть)
```cpp
extern "C" int ieee80211_raw_frame_sanity_check(int32_t arg, int32_t, int32_t) {
    return (arg == 31337) ? 1 : 0;
}
```
после этого загрузите код в IDE, Подключите плату к компьютеру, вставьте код и сделайте прошивку

# измените в коде следующие строчки для подключения к микроконтроллеру
```cpp
const char* AP_SSID = "ESP32_DEAUTH";
const char* AP_PASS = "12345678";
```
задайте своё имя и пароль (пароль только от 8 символов!)

# Возможности, что и как?
1. Включение и выключение атаки происходит по кнопке boot (GPIO0), если светодиод по GPIO2 засветился = атака включена, если нет = выключена

2. что бы получить доступ к SSID, и другим данным, подключитесь к точке доступа ESP32 указанным паролем ранее в коде и перейдите по http://192.168.4.1 (или аналогичный локальный адрес, но обычно такой)
3. в панели вы можете настроить SSID (имя сети для атаки), а так же следующие данные:

1. Режим (ожидание или атака)
2. Текущая цель (имя SSID)
3. найденный SSID (если нашлась точка с таким именем)
4. BBSSID цели (MAC адрес)
5. Цель захвачена (да или нет)
6. сканирование (да или нет)
7. отправлено пакетов (кол. во отправленных пакетов за всё время работы ESP32)
8. время атаки (сколько прошло времени с момента включения)
9. Uptime (сколько работает ESP32)
10. IP точки доступа (локальный IP)
11. клиентов на AP (кол. во устройств подключенных к ESP32)

атака отправляет специальные кадры
```cpp
uint8_t deauthPacket[26] = {
  0xA0, 0x00, 0x00, 0x00,
  0xFF, 0xFF, 0xFF, 0xFF, 0xFF, 0xFF,
  0x00, 0x00, 0x00, 0x00, 0x00, 0x00,
  0x00, 0x00, 0x00, 0x00, 0x00, 0x00,
  0x00, 0x00,
  0x08, 0x00
};
```
которые заставляют роутер отключить всех устройств которые были подключены к нему, спамя этим
тем самым выводя роутер из строя (Denial of Service/DoS)

у новых роутеров от такого есть защита, по этому стоит убедится что у роутера жертвы нет такой защиты
